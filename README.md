# Droid-VM 组织资料（本地工作副本）

此目录用于维护 [Droid-VM](https://github.com/Droid-VM) 组织的 GitHub 简介素材，
保存一份到本地以便后续修改与同步。

## 结构

```
Droid-VM/
└── .github/
    └── profile/
        ├── README.md     # 组织介绍（将放到 org 的 .github 仓库后即成为首页简介）
        └── logo.png      # 组织头像（沿用 DroidVM 应用图标，源自主仓库 DroidVM-Docs）
```

> GitHub 约定：组织账号下建一个名为 `.github` 的仓库，把本目录中
> `.github/profile/README.md`（及图片等资源）提交进去，即成为组织首页的简介。
> 更完整的组织素材（仓库清单等）也可用 [Droid-VM 仓库列表](https://github.com/orgs/Droid-VM/repositories)
> 核对。

## 内容口径（截至 2026-09-07）

- 仓库清单、描述、分支约定、徽章等均按 GitHub API 实际查询整理。
- 分支约定：除应用本体 `DroidVM` 用 `master` 外，其余仓库稳定分支统一为 `droidvm`。
- 文档站点：<https://droid-vm.github.io/>。
